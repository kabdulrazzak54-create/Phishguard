Privacy and data handling

  • Submitted URLs are analyzed in memory and are not fetched or opened.
  • Uploaded QR images are decoded in memory and are not stored.
  • Logs record only the score, category and rule count, never full URLs or API keys.
  • Scan history is off by default. If you tick the box, only a scan ID, time, score, category, a salted SHA-256 hash of the registered domain and rule names are saved. You can delete everything on the History page.
  • If the operator enables the optional Google Safe Browsing check, the submitted URL is sent to Google for that lookup.
  • Never type passwords, OTPs, UPI PINs or card numbers into this tool.
